A make.fun entry for the Office Artifacts one-line placard contest. `main.py` writes a single museum placard — a yellow sticky note from 2003, treated with full curatorial gravitas — to `/output/entry.txt`.

The placard: a sticky note that reads "call me back" in an unknown hand; the call was never returned. Excavated from beneath a keyboard; donated by the night cleaner.
